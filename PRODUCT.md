# NVT Du Lịch

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Vietnamese-speaking visitors exploring destinations, tours and hotels; signed-in customers booking services and planning personal trips; administrators managing the existing catalog and operations.

## Product Purpose

Help visitors choose a Vietnam trip, find accommodation and organize a day-by-day itinerary using the existing catalog and backend.

## Capabilities and Constraints

Preserve current working features and the recovered baseline from 2026-09-26. Public catalog browsing, authenticated booking/planning and administrative workflows remain. Do not restore rolled-back features implicitly. Do not mutate the database for visual design. Test with existing SQL accounts, not newly created accounts. No invented ratings, testimonials, prices or availability; no new AI chatbot promise.

## Brand Commitments

The user confirmed on 2026-09-26: retain NVT branding, real destination imagery/data and existing functionality. Reference https://www.perusi.io.vn/ for photographic scale, typography, fullscreen navigation and motion, with a distinct NVT identity rather than a literal copy. The user wants a less generic, less AI-looking interface. Customer-facing pages should share this direction; administration remains task-oriented. Page transitions should be deliberately slower than the previous 0.45-second version.

## Evidence on Hand

Existing backend catalog and media library, with source attribution. Route and API ownership in docs/CODEBASE_MAP.md. Local reference captures in .local/ref-home.jpg, .local/ref-menu.jpg and .local/ref-mobile.jpg. These are visual reference evidence, not assets to republish.

## Product Principles

- Let actual destinations and useful travel information lead.
- Make discovery inviting and booking tasks clear.
- Preserve Vietnamese legibility, keyboard access, mobile usability and reduced-motion behavior.
- Keep core functionality and data truthful while changing presentation.

## Open Decisions

Homepage composition awaits approval of three visual mockups. No new functionality or commercial claims are authorized by this redesign.
