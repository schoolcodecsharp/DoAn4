# Tài liệu kỹ thuật cũ

Các file này được giữ để tra cứu lịch sử, không được ứng dụng hiện tại sử dụng.

- `sql/`: các lần sửa/nhập dữ liệu trước đây. Không chạy lại trên database đang dùng.
- `generators/`: script sinh CRUD cũ; chạy lại có thể ghi đè mã đã sửa.
- `logs/`: đầu ra và lỗi từ các lần thao tác SQL trước đây.

Cài đặt mới dùng `database/` theo README gốc. Không có dữ liệu database nào bị thay đổi trong lần sắp xếp thư mục này.
